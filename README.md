# Метро Москвы 3D

**Открыть: https://dmitryolkhovoi.github.io/moscow-metro-3d/**

Трёхмерная схема Московского метро в браузере: станции и пути в реальных координатах (метры),
на реальной глубине заложения, поверх карты Москвы. Построитель маршрутов, поездка на поезде
и мини-игра «Машинист». Оформление — по мотивам навигации московского транспорта (неофициальный проект,
без фирменного логотипа и шрифта; шрифт — Golos Text).

## Запуск

```sh
python3 scripts/serve.py      # или npm start
```

Локально — открыть http://localhost:8080. Сборка не нужна, three.js грузится с jsDelivr. `scripts/serve.py` — простой
сервер без кэширования, чтобы после правок браузер не держал старые модули.

Перед публикацией: `npm run stamp` — проставляет метку версии (`?v=…`) на стили и модули, чтобы после деплоя
на GitHub Pages браузер сразу брал новые файлы, а не кэш.

## Возможности

- **Схема**: левая кнопка мыши — вращение, правая — сдвиг, колесо — масштаб к курсору.
  Клик по станции — карточка: глубина и её источник, перегоны (по путям и по прямой), пересадки, кнопки «Отсюда»/«Сюда».
- **Маршрут**: «Откуда → Куда» с автодополнением или «Случайный маршрут». Кратчайший по времени путь
  с пересадками, время ≈ (50 км/ч в движении, 30 с стоянка, переход пешком + ожидание поезда).
  Маршрут подсвечивается в 3D, остальные линии приглушаются.
- **Поездка**: автопилот провозит поезд по реальным путям и глубинам, камера следует за составом
  (вращать и приближать можно на ходу). Ускорение времени ×1…×12.
- **Машинист** (мини-игра): ведите состав сами и останавливайтесь у платформы.
  - ↑/W — ускорение, ↓/S — тормоз, пробел — экстренный, V — кабина, M — звук, C — камера следует/свободна, Esc — выход;
    на телефоне — экранные кнопки «Ускорение» и «Тормоз».
  - Остановка: ≤3 м — 100 очков, ≤10 м — 70, ≤30 м — 40, ≤80 м — 10. Проезд станции −50,
    превышение 80 км/ч — −5 очков в секунду. Шкала платформы в HUD появляется за 400 м.
- **Кабина машиниста** (V или кнопка в HUD, в «Поездке» и «Машинисте»): вид с головы состава в реальном масштабе —
  тоннель из тюбингов со светильниками и кабелями, рельсы и шпалы, фара, светлые залы подземных станций с табличками,
  наземные платформы с навесами. Пульт: спидометр, лампы допустимой скорости «0 40 60 70 80», рукоятка контроллера.
  Мышью можно осмотреться (двойной клик — вперёд).
- **Звук**: настоящие записи московского метро — стоянка, ход (высота меняется со скоростью), разгон и торможение,
  двери (см. `sounds/CREDITS.md`). Объявления как в метро: «Осторожно, двери закрываются. Следующая станция — …»,
  «Станция …, переход на … линию», «Конечная…». Голос — синтез речи браузера; к центру — мужской, от центра — женский
  (если в системе есть оба русских голоса). Включается в «Вид» или кнопкой в HUD.
- **Вид**: тема (светлая по умолчанию / тёмная), масштаб глубины (×1 — реальные пропорции), подложка светлая/тёмная/улицы/спутник (тайлы Esri),
  виды «3D», «Сверху», «Разрез», «Линейка» (3D-расстояние между двумя станциями).
- В консоли доступен `window.metro3d` (камера, сцена, роутер, текущая поездка).

## Данные

`data/metro.json` собирается скриптом и лежит в репозитории:

```sh
node scripts/build-data.mjs            # из кэша scripts/.cache
node scripts/build-data.mjs --refresh  # скачать заново
```

| Что | Источник |
|---|---|
| Линии, порядок станций, геометрия путей, тоннели/мосты | OpenStreetMap (Overpass): маршруты `route=subway` + МЦК |
| Глубина заложения | Wikidata (P4511), при отсутствии — инфобокс русской Википедии |
| Нет данных о глубине | оценка: мелкого заложения ≈ 12 м, иначе среднее соседей (в карточке помечено «оценка») |
| Пересадки | Wikidata (P833) + короткий ручной список пересадок МЦК + станции разных линий ближе 150 м или одноимённые в пределах 800 м |

Глубина отсчитывается от поверхности (рельеф не учитывается). Наземные станции — 0 м, на мостах/эстакадах — до +8 м.
Профиль тоннеля между станциями — линейная интерполяция глубин, у порталов и мостов уклон не круче 40‰.
Длины перегонов считаются вдоль путей OSM с учётом перепада глубин; длина пересадки — расстояние
между центрами станций, а не длина перехода. Время в пути — модельная оценка, не расписание.

МЦД не включены (это пригородные поезда). Монорельс в OSM отсутствует.

## Структура

```
index.html, styles.css
src/main.js        — рендерер, камера, выбор мышью, линейка, маршрут/поездка, цикл
src/scene.js       — пути, станции, вертикали, пересадки, подписи, подсветка маршрута
src/router.js      — граф станций и Дейкстра по времени
src/train.js       — поезд: автопилот, мини-игра «Машинист», объявления на стоянках
src/cab.js         — вид из кабины: тоннель, станции, рельсы, пульт
src/audio.js       — звуки поездки и тексты объявлений
sounds/            — нарезанные записи метро и CREDITS.md
scripts/serve.py   — локальный сервер без кэширования
scripts/stamp.mjs  — метка версии для сброса кэша после деплоя
src/basemap.js     — подложка из тайлов (базовый слой + детальный вокруг точки обзора)
src/ui.js          — панель (маршрут/вид/линии), автодополнение, карточки, HUD, тосты
src/projection.js  — проекция lat/lon → метры (общая для браузера и скрипта)
scripts/build-data.mjs
data/metro.json
```
